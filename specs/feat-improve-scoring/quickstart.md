# Quickstart: Implementing Improve Scoring

1. Ensure you are on the feature branch: `feat-improve-scoring`
2. Add or verify `NEW-QUIZ-SCORING.md` and `NEW-EGG-JUGGLING-SCORING.md` formulas in the repo root.
3. Install dev dependencies: `npm install`
4. Run unit tests for scoring utils (once implemented): `npm test -- src/utils/__tests__/scoring.test.js`
5. Run the full test suite: `npm test`
6. Lint and format: `npm run lint` and `npm run format`

Feature flag: set environment variable `ENABLE_NEW_SCORING=true` during development to enable the new scoring logic.
