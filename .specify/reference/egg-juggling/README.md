I want to add a feature into this existing project.
From the landing screen, when a user selects a quiz, it goes to quiz page showing the 1st question of the quiz.
Now, at the left panel of this question page, I want to add a 2D mini-game with the purpose of confusing or making the user to lose focus on the quiz like selecting wrong answers or ran out of time because of playing this other mini game.
The mini-game will about juggling eggs.
While quiz is not yet finished, eggs will randomly drop from above and going down to hit the bottom of the screen.
The goal of the user is to NOT let the eggs drop by tapping on it.
If the user taps on the egg, it will bounce up a little and then drop again.
After some time, another egg will drop creating of the scenario where the user will need to jug multiple eggs and user should not drop them.
If an egg hits the bottom of the screen, the user will lose a point.
If the user manage to save all the eggs, he will get bonus points on top of the default quiz points.
After the finishes all the quiz or the time runs out, calculate all the points from the normal quiz plus the eggs from the points.
Put some settings control toggle this mini-game.
Put some settings control on how many eggs to show up during the quiz.

The mini-game will be implemented using HTML5 Canvas and JavaScript.
Modularise the src code of this game so it can easily be integrated to other web apps.
