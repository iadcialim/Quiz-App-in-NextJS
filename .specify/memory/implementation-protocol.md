# Implementation Protocol

**Task Approval**: Always request and receive user confirmation before implementing any task  
**Enforcement**: Mandatory for all implementation activities  
**Validation**: Explicit user approval required  
**Confirmation Commands**: "do", "implement", "yes", or explicit confirmation phrases

## Recognized Confirmation Commands

- "do [task]" - Direct confirmation to proceed with task
- "implement [task]" - Direct confirmation to proceed with task  
- "yes" - Explicit approval
- Any explicit confirmation phrase

## Process

1. Present task details and requirements
2. Wait for user confirmation using recognized commands
3. Proceed only after receiving valid confirmation
4. Mark task as completed upon successful implementation
